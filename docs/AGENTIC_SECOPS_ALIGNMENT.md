# Agentic SecOps Alignment — gunnchAI3k

**Role lane:** Google / Mandiant — Associate Security Analyst, Agentic Security Operations

This **role-aligned proof path** demonstrates defensive, educational, mock-safe security operations patterns using the gunnchAI3k repo as an **Agentic SecOps Lab**.

## Skills demonstrated

- AI-assisted alert triage (documented workflow; offline mock extractor)
- IOC extraction from unstructured threat reports
- Incident summarization templates
- Defensive detection logic (YARA-L / Sigma-style **mock** skeletons)
- Containment recommendation playbooks
- GenAI risk documentation (hallucination, prompt injection, data leakage)
- Mock SIEM-like telemetry handling (synthetic reports only)

## What this proves

- I can build a structured **defensive security workflow** using AI-assisted analysis patterns.
- I can convert unstructured threat information into structured indicators and detection ideas.
- I can document safety limits and privacy boundaries.

## What this does not claim

- This is not connected to a real SIEM.
- This does not process real customer data.
- This does not analyze live malware.
- This is not a production SOC automation platform.
