# SecOps Privacy and Safety

- **Mock data only** in this lab path
- **No real customer data**, credentials, tokens, or private logs
- **No live malware** or exploit instructions
- **No unauthorized transmission** of extracted IOCs to external APIs in default scripts
- **Youth safety:** classroom demos use synthetic scenarios only
- **Redaction** before any future cloud-model use
- **Aggregated reporting** for any future field telemetry (see edge-io policies)
