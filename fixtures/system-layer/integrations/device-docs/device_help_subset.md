# Device docs subset (local RAG)

Student / handheld / DS-XL local troubleshooting notes for gunnchOS integration.

## Storage health
1. Check free disk and reclaimable caches.
2. Prefer local-only diagnostics; do not upload device logs without consent.
3. Boot manifests and ring_input evidence stay on-device unless explicitly exported.

## Connectivity
Prefer Wi-Fi/local LAN. Cellular is optional and requires consent for non-sensitive tasks.
Offline mode must keep tutoring, device help, and safety alerts available.
